# Step 01-02 — 내장 LED 출력 핀 설정

2주차 강의노트 70쪽의 내장 LED 예제 중 핀 정의와 `setup()`을 먼저 작성합니다.

## 구현
1. `git switch step-01-02-led-output`
2. 상단에 `#define LED 2`를 작성합니다.
3. `setup()`에서 `pinMode(LED, OUTPUT);`을 실행합니다.
4. `loop()`에는 아직 점멸 코드를 작성하지 않습니다.

## 검증
```bash
pio run -e esp32dev_usb
git diff step-01-02-led-output..step-01-02-led-output-done -- src/main.cpp
```
빌드가 성공하면 다음 서브스텝에서 `loop()`을 구현합니다.
