# Step 01-02 — 내장 LED 점멸

## 목표
`loop()`에서 LED를 500ms 간격으로 켜고 끕니다.

## 실습
1. `git switch step-01-02-led-blink`
2. `loop()`에 `delay(500)`과 `digitalWrite()`를 작성합니다.
3. 강의 예제 순서대로 `delay(500)` → `HIGH` → `delay(500)` → `LOW`를 사용합니다.
4. `pio run -e esp32dev_usb`로 빌드·업로드합니다.
5. 내장 LED가 0.5초씩 점멸하는지 확인합니다.
6. `step-01-02-led-blink-done`과 코드를 비교합니다.

```bash
git diff step-01-02-led-blink..step-01-02-led-blink-done -- src/main.cpp
```
