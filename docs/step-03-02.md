# Step 03-02 — 밝기 변경 속도

## 실습 목표
밝기 변경 속도를 실습합니다.

## 브랜치
- 시작: `git switch step-03-02-fade-speed`
- 완료: `git switch step-03-02-fade-speed-done`
- 코드 비교: `git diff step-03-02-fade-speed..step-03-02-fade-speed-done -- src/main.cpp platformio.ini`

## 배선·준비
- GPIO25 LED와 220Ω 저항
- ESP32 DOIT DevKit V1, VS Code + PlatformIO, USB 케이블

## 코드 구현
- 사용하는 코드: `fadeAmount=1, 밝기 경계 250, delay(2)`
- 참고: 3주차 18~21쪽
- 이번 단계의 기능만 추가하고 기존 LED·버튼 동작을 확인하세요.

## 실행 및 검증
1. 시작 브랜치를 체크아웃합니다.
2. `src/main.cpp`와 `platformio.ini`에서 이번 단계의 수정 위치를 확인합니다.
3. `pio run -e esp32usb`로 빌드하고 보드에 업로드합니다.
4. 기존 코드와 LED 점멸 주기를 비교합니다.
5. 완성 코드와 변경점을 비교합니다.

## 문제 해결
- 빌드 실패: 선택한 ESP32 보드와 USB 업로드 환경을 확인하세요.
- LED가 작동하지 않으면 GPIO25, 저항, LED 극성과 GND를 확인하세요.
- 버튼 입력이 예상과 반대이면 Pull-up / Pull-down 회로와 LOW/HIGH 기준을 확인하세요.
