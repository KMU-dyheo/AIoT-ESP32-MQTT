# Step 01-01 — 시리얼 모니터

2주차 강의노트 20~22쪽의 `Hello World!` 출력 예제를 작성합니다.

## 구현
1. `git switch step-01-01-serial`
2. `setup()`에서 `Serial.begin(115200);`을 호출합니다.
3. 강의 예제의 `while (!Serial) { ; }`을 작성합니다.
4. `loop()`에서 `Serial.println("Hello World!");`을 호출합니다.
5. 다음 줄에서 `delay(1000);`으로 1초 대기합니다.

## 검증
```bash
pio run -e esp32dev_usb
pio device monitor -b 115200
git diff step-01-01-serial..step-01-01-serial-done -- src/main.cpp
```
시리얼 모니터에 `Hello World!`가 약 1초마다 출력되는지 확인합니다.
