# Step 01-01 — LED 출력 핀 설정

## 목표
ESP32의 GPIO 2를 LED 출력으로 초기화합니다.

## 실습
1. `git switch step-01-01-led-output`
2. `#define LED 2`를 작성합니다.
3. `setup()`에서 `pinMode(LED, OUTPUT);`을 실행합니다.
4. `loop()`에는 아직 LED 점멸 코드를 넣지 않습니다.
5. `pio run -e esp32dev_usb`로 빌드합니다.
6. `step-01-01-led-output-done`과 코드를 비교합니다.

```bash
git diff step-01-01-led-output..step-01-01-led-output-done -- src/main.cpp
```
