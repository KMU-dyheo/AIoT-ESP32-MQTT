# Step 08-04 — Wi-Fi 연결

## 시작 코드
`git switch step-08-04-wifi-connect`

## 실습
1. `include/wifi_config.example.h`를 `include/wifi_config.h`로 복사해 사용하는 네트워크에 맞게 수정합니다.
2. `setup()`에서 `setupApplication()`을 호출한 후 Wi-Fi 연결 코드를 실행합니다.
3. `loop()`에서는 `loopApplication()`을 먼저 호출하고 Wi-Fi 연결 상태를 확인합니다.
4. Wi-Fi가 연결되지 않아도 버튼과 LED가 정상 작동하는지 관찰합니다.

## 완료 코드
`git switch step-08-04-wifi-connect-done`

```bash
git diff step-08-04-wifi-connect..step-08-04-wifi-connect-done -- src/main.cpp
```

Wi-Fi 설정 파일의 비밀번호는 Git에 업로드하지 않습니다.
