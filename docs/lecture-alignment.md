# 「IoT기초 - IOT 빅데이터」와 ESP32 실습 연결

> 자료 출처: 업로드한 81페이지 강의노트. 아래 슬라이드 페이지와 핵심 개념은 강의노트에 근거하며, ESP32 실습 단계 연결은 교육과정 설계임.

| 강의노트 | 원문 핵심 내용 | 연결되는 실습 | 연결 방식 |
|---|---|---|---|
| 3~11쪽 | IoT와 빅데이터, 데이터·AI, 정형/반정형/비정형 데이터 | Step 05~07, 10 | 버튼 이벤트·LED 상태를 측정 가능한 데이터로 표현 |
| 12~24쪽 | 속도, 구조, 저장, 전처리, 데이터 습득 및 표현 | Step 06, 10 | 버튼 디바운싱과 이벤트 발생/발행의 차이 관찰 |
| 25~44쪽 | 클라우드 컴퓨팅 및 IoT 클라우드 구성 | Step 08, 12 | 장치와 네트워크·클라우드 역할 구분 |
| **45~46쪽** | MQTT, 브로커 기반 통신, Publish/Subscribe, QoS 0·1·2 | **Step 09~11** | 로컬 Mosquitto 연결·발행·구독·LED 원격 제어 |
| 47~50쪽 | SQL/NoSQL, 웹앱·모바일앱 서비스 | Step 10~13 토론 | 클라우드에 전달된 상태정보의 활용 사례 논의. DB/웹앱 코드는 현 커리큘럼에 포함하지 않음 |
| 51~60쪽 | 에지 컴퓨팅, 로컬 처리와 피드백 | Step 04~08 | 네트워크 단절 상황에서도 로컬 버튼/LED 제어 유지 |
| 61~73쪽 | 포그 컴퓨팅, 지연·대역폭·신뢰성·보안 문제 | Step 08~13 | 실시간 로컬 제어와 원격 메시지 처리 분리, 장애와 지연 비교 |
| 74~81쪽 | 자율주행·헬스케어·리테일·스마트 빌딩 사례 | Step 12~13 토론 | 측정→판단→제어의 산업 응용으로 확장 |

## 주의할 구분

- 강의노트에는 ESP32 GPIO, PlatformIO, PWM, `millis()`, ArduinoOTA, AWS IoT 인증서 설정을 직접 구현하는 순서가 수록되어 있지 않음.
- Step 01~13의 코딩 순서는 **강의노트 개념을 체험하기 위해 추가 설계한 실습 커리큘럼**임.
- 서브스텝이 생기면 `step-XX-YY-설명` / `step-XX-YY-설명-done`으로 분리하고, 완료 코드가 다음 서브스텝의 시작 코드가 되도록 함.
- 각 Step의 시작과 완료는 `src/main.cpp`와 도입되는 설정·라이브러리의 차이로 검증.
