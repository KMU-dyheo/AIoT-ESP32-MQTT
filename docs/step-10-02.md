# Step 10-02 — LED Fade 실행 상태 전송

## 시작 및 완료
- 시작: `step-10-02-led-state` — Step 10-01 완료 코드
- 완료: `step-10-02-led-state-done`

## 구현 과제
- ledEnabled가 토글될 때마다 상태를 발행하고 연결 직후의 초기 상태도 발행
- Topic: `aiot/esp32-01/led/state`
- Payload: `on / off`
- `updateButton()`·`updateBrightness()`를 제거하거나 네트워크 통신 때문에 중단하지 않음

## 실습
1. 현재 시작 브랜치를 checkout
2. `src/main.cpp`에서 `serviceMqtt()`와 로컬 상태 업데이트 비교
3. 바뀐 상태만 `mqttClient.publish()` 호출
4. PC Mosquitto `mosquitto_sub -h BROKER_PC_IP -t "aiot/esp32-01/led/state" -v`로 확인
5. 완료 브랜치와 `git diff`로 비교

## 개발 환경
- 실제 사용 보드: `esp32doit-devkit-v1`, ESP32 240MHz, Arduino Framework, Serial 115200
- LED: GPIO25, 220~330Ω 직렬저항
- 버튼: GPIO23 ↔ GND, `INPUT_PULLUP` (눌림 LOW, 해제 HIGH)
- 빌드: `pio run -e esp32usb`
