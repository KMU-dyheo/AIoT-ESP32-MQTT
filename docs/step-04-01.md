# Step 04-01 — loop 재진입 시간 측정

## 실습 목표
loop 재진입 시간 측정를 실습합니다.

## 브랜치
- 시작: `git switch step-04-01-loop-timing`
- 완료: `git switch step-04-01-loop-timing-done`
- 코드 비교: `git diff step-04-01-loop-timing..step-04-01-loop-timing-done -- src/main.cpp platformio.ini`

## 배선·준비
- ESP32 USB 연결
- ESP32 DOIT DevKit V1, VS Code + PlatformIO, USB 케이블

## 코드 구현
- 사용하는 코드: `micros(), Serial.print(), 반복횟수 count, 평균 sum/count`
- 참고: 3주차 26~28쪽
- 이번 단계의 기능만 추가하고 기존 LED·버튼 동작을 확인하세요.

## 실행 및 검증
1. 시작 브랜치를 체크아웃합니다.
2. `src/main.cpp`와 `platformio.ini`에서 이번 단계의 수정 위치를 확인합니다.
3. `pio run -e esp32usb`로 빌드하고 보드에 업로드합니다.
4. loop() 실행 간격을 시리얼 모니터로 확인합니다.
5. 완성 코드와 변경점을 비교합니다.

## 문제 해결
- 빌드 실패: 선택한 ESP32 보드와 USB 업로드 환경을 확인하세요.
- LED가 작동하지 않으면 GPIO25, 저항, LED 극성과 GND를 확인하세요.
- 버튼 입력이 예상과 반대이면 Pull-up / Pull-down 회로와 LOW/HIGH 기준을 확인하세요.
