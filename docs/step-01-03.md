# Step 01-03 — 내장 LED 500ms 점멸

2주차 강의노트 70쪽의 코드 순서를 사용합니다.

## 구현
1. `git switch step-01-03-led-blink`
2. `setup()`의 `pinMode(LED, OUTPUT);`은 유지합니다.
3. `loop()`에 아래의 네 줄을 순서대로 추가합니다.

```cpp
delay(500);
digitalWrite(LED, HIGH);
delay(500);
digitalWrite(LED, LOW);
```

## 검증
```bash
pio run -e esp32dev_usb
git diff step-01-03-led-blink..step-01-03-led-blink-done -- src/main.cpp
```
내장 LED가 약 0.5초마다 켜졌다 꺼지는지 확인합니다.
