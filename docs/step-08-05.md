# Step 08-05 — OTA 업로드 준비

## 시작 코드
`git switch step-08-05-ota`

## 실습
1. 기존 Wi-Fi 연결 코드와 `setupApplication()`, `loopApplication()`을 유지합니다.
2. Wi-Fi 연결 후 `ArduinoOTA.begin()`을 호출하도록 준비합니다.
3. `loop()`에서 먼저 `loopApplication()`을 실행한 후 `ArduinoOTA.handle()`로 업로드 요청을 처리합니다.
4. `platformio.ini`의 `esp32ota` 업로드 환경에 실제 장치 IP 및 인증 정보를 설정합니다.
5. Wi-Fi를 끊은 뒤에도 기존 버튼·LED 기능이 동작하는지 확인합니다.

## 완료 코드
`git switch step-08-05-ota-done`

```bash
git diff step-08-05-ota..step-08-05-ota-done -- src/main.cpp platformio.ini
```

OTA 업로드는 USB로 처음 펌웨어를 설치한 뒤 실행합니다. 장치 비밀번호는 공개 저장소에 포함하지 않습니다.
